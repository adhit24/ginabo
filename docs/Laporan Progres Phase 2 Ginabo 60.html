Integrasi Pihak Ketiga

Website perlu terhubung dengan layanan eksternal.

Untuk menjalankan pembayaran online dan perhitungan ongkir secara otomatis, website Ginabo perlu berintegrasi dengan pihak ketiga. Contohnya adalah Midtrans untuk pembayaran dan Raja Ongkir untuk perhitungan biaya pengiriman. Proses ini membutuhkan akses akun, API key, konfigurasi teknis, serta pengecekan dari sisi penyedia layanan. Jadwal penyelesaian dapat berjalan sesuai target apabila akses dan data konfigurasi tersedia tepat waktu.

Perlu koordinasi

Midtrans

Digunakan agar pelanggan dapat melakukan pembayaran melalui metode seperti transfer bank, virtual account, e-wallet, atau metode lain yang tersedia sesuai akun Midtrans Ginabo. Hal yang perlu disiapkan meliputi akun merchant, mode sandbox/production, server key, client key, dan metode pembayaran yang ingin diaktifkan.

Perlu koordinasi

Raja Ongkir

Digunakan untuk membantu menghitung biaya pengiriman berdasarkan alamat tujuan, kota asal pengiriman, berat barang, dan pilihan kurir yang akan digunakan. Hal yang perlu disiapkan meliputi API key, alamat asal pengiriman, daftar kurir, serta standar berat atau dimensi produk.

Sisa Pekerjaan Phase 2

Karena progres saat ini berada di 60%, sisa pekerjaan utama adalah menyelesaikan bagian yang berhubungan dengan transaksi, validasi, dan pengetesan sebelum diserahkan untuk review. Target penyelesaian Phase 2 adalah 3 Agustus 2026.

Memastikan tampilan tidak berantakan dan proses belanja berjalan baik di berbagai ukuran layar.

Menyiapkan hasil Phase 2 untuk dicek bersama pihak Ginabo sebelum masuk ke penyempurnaan berikutnya.

Hal Yang Dibutuhkan Dari Ginabo

Agar target 3 Agustus 2026 dapat dijaga, beberapa informasi berikut perlu tersedia untuk proses integrasi dan pengujian transaksi.

Dibutuhkan

Akses layanan pembayaran

Jika Midtrans akan digunakan, dibutuhkan informasi akun, mode sandbox/production, dan API key yang diberikan oleh Midtrans.

Dibutuhkan

Akses layanan ongkir

Jika Raja Ongkir akan digunakan, dibutuhkan API key, alamat asal pengiriman, kurir yang ingin ditampilkan, serta aturan berat produk.

Dibutuhkan

Data operasional pengiriman

Dibutuhkan alamat gudang atau titik pengiriman utama, daftar kurir yang dipakai, serta aturan jika ada produk dengan berat khusus.

Perlu keputusan

Metode pembayaran aktif

Perlu dipastikan metode pembayaran mana saja yang akan ditampilkan ke pelanggan agar konfigurasi payment gateway sesuai kebutuhan operasional Ginabo.
