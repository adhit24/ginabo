Midtrans is a payment processing platform that provides businesses with the ability to accept and send payments online. Midtrans's API allows businesses to integrate Midtrans's payment processing capabilities into their own websites and applications, allowing them to accept payments from their customers easily and securely.

Midtrans API is organized around REST (Representational State Transfer) to provide a simple, predictable interface. <br />

# <b>Accepting Payments</b>

[**Built-in Interface (Snap) API**](/reference/getting-started-with-snap) <span style={{ color: "orange" }}><sup>Recommended</sup></span>\
Accept payments using Midtrans's prebuilt hosted checkout page that is optimized to increase payment conversion. Fastest way to integrate to Midtrans.

[**Custom Interface - Core API**](/reference/core-api-overview)\
Build your own checkout page and integrate it to Midtrans's payment API via Core API.

[**Mobile SDK**](/reference/mobilesdk-getting-started)\
SDKs to accept payment in your mobile app without having to code everything from scratch.

[**Payment Links API**](/reference/overview-12)\
No code payment solution. Generate a link via dashboard or API and share it to your customers to pay with.
